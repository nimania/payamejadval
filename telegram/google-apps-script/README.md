# پیام جدول در Google Apps Script — راه‌اندازی و به‌روزرسانی

نسخهٔ جاری برای `@PayameJadvalBot`، بدون Vercel، شمارهٔ تلفن خارجی، وب‌هوک یا اتصال GitHub به حساب گوگل است.

**توجه:** مخزن GitHub منبع کد است؛ برنامهٔ موجود در حساب Google Apps Script کاربر **خودکار با GitHub همگام نمی‌شود**. تغییر منو و اشتراک‌گذاری، بعد از جایگزینی محتوای `Code.gs` در Apps Script کاربر فعال خواهد شد.

## فعال‌کردن نسخهٔ تازه روی پروژهٔ موجود (مهم)

۱. از [Code.gs](Code.gs) تمام کد فعلی را کپی کن.

۲. پروژهٔ Google Apps Script قبلی با نام `Payame Jadval Bot` را در https://script.google.com/home باز کن؛ به **همان پروژهٔ موجود** برو، پروژهٔ دوم نساز.

۳. در ویرایشگر، محتوای `Code.gs` را با نسخهٔ تازه جایگزین و **Save** کن. مقدار ذخیره‌شده در **Project Settings → Script Properties → TELEGRAM_CROSSWORD_BOT_TOKEN** با تعویض کد پاک نمی‌شود؛ آن را داخل کد نگذار و در چت نفرست.

۴. معمولاً نیازی به اجرای دوبارهٔ `setupBot` نیست چون Trigger قبلیِ `pollUpdates` برقرار است. برای آزمایش، پس از Save در تلگرام `/start` بفرست، سپس تابع `testNow` را دستی Run کن یا اجرای خودکار دقیقه‌ای را بررسی کن. اگر Trigger از قبل حذف شده، **فقط آن‌وقت** `setupBot` را یک‌بار اجرا کن.

۵. منوی تازه باید ۶ گزینه داشته باشد: **⚡ جدول سریع، 🧩 جدول اصلی، 🏆 چالش جمعه، 📚 آرشیو جدول‌ها، 🏅 امتیازهای من، 📤 اشتراک‌گذاری**.

۶. «جدول سریع» در **۱۱ و ۱۲ نوامبر ۲۰۲۶** دو نمونهٔ ۵×۵ از پیش منتشرشده را ارائه می‌کند. در تاریخ‌هایی که جدول تأییدشدهٔ تازه‌ای نداریم، ربات **صریحاً نبود جدول را اعلام می‌کند**. «جدول اصلی» تا انتشار جدول ۷×۷ معتبر روزانه، همان نمونهٔ آزمایشی ۷×۷ را با برچسب آزمایشی عرضه می‌کند.

۷. برای دیدن **دکمهٔ کپی لینک** و **امتیاز آزمایشی** باید جدول جدید را از ربات بگیری؛ HTML پیام‌های Widget قدیمی تغییر نمی‌کند. دکمهٔ «اشتراک‌گذاری» لینک مستقیم ورود به **همان جدول** در ربات، و یک لینک وب ویژهٔ همان جدول برای ارسال در پیام‌رسان‌های دیگر فراهم می‌کند.

## راه‌اندازی برای اولین بار

اگر اصلاً Google Apps Script فعال نکرده‌ای:
- با حساب گوگلت وارد https://script.google.com/home/projects/create شو و پروژهٔ `Payame Jadval Bot` بساز.
- کد [Code.gs](Code.gs) را جایگزین کن.
- در **Project Settings → Script Properties** مقدار محرمانهٔ `TELEGRAM_CROSSWORD_BOT_TOKEN` را از `@BotFather` ذخیره کن.
- یک بار `setupBot` را اجرا کن و مجوزهای موردنیاز Google Apps Script را بررسی و تأیید کن.
- `/start` را دوباره برای ربات بفرست و در صورت نیاز `testNow` را اجرا کن.

## محدودیت‌های فعلی

- این ربات هر **حدود یک دقیقه** پیام‌ها را بررسی می‌کند، نه فوراً. زمان دقیق اجرای trigger تضمین‌شده نیست.
- `widget_query` در تلگرام باید ظرف ۱۵ ثانیه پاسخ بگیرد و با **پولینگ یک‌دقیقه‌ای مناسب نیست**؛ بنابراین `allow_queries` غیرفعال است و **امتیاز رسمی سروری یا جدول رتبه‌بندی واقعی هنوز فعال نیست**.
- دو مینی ۵×۵ با تأیید اولیهٔ ویراستار از `data/mini-puzzles.json` برای ۱۱ و ۱۲ نوامبر در `telegram/catalog.json` زمان‌بندی شده‌اند. انتشار هر روزِ تازه به موجودی جدول‌های جدید و بازبینی بستگی دارد.
- چالش ۹×۹ جمعه تا افزودن سازگاری و کنترل کیفیت ۹×۹ و وجود جدول جدید فعال نمی‌شود.
- فوروارد مستقیم Widget در تلگرامِ عمومی پشتیبانی نمی‌شود؛ **اشتراک لینک خود جدول** جایگزین است.
- پل قدیمی GitHub با زمان‌بندی پنج‌دقیقه‌ای غیرفعال است. نسخهٔ زمان‌بندی‌شدهٔ این Apps Script و پل دستی GitHub را هم‌زمان اجرا نکن تا رویدادهای `getUpdates` از دست نروند.
- برای توقف `stopBot` را اجرا کن؛ ربات‌های دیگر دست‌نخورده می‌مانند.
