# پیام جدول در Google Apps Script — راه‌اندازی و به‌روزرسانی

نسخهٔ جاری برای `@PayameJadvalBot`، بدون Vercel، شمارهٔ تلفن خارجی، وب‌هوک یا اتصال GitHub به حساب گوگل است.

**توجه:** مخزن GitHub منبع کد است؛ برنامهٔ موجود در حساب Google Apps Script کاربر **خودکار با GitHub همگام نمی‌شود**. تغییر منو و اشتراک‌گذاری، بعد از جایگزینی محتوای `Code.gs` در Apps Script کاربر فعال خواهد شد.

## افزودن سودوکو و داشبورد آمار (نسخهٔ ۱۱ نوامبر ۲۰۲۶)

**وضعیت کد:** در [Code.gs](Code.gs) منوی سودوکوی آسان/متوسط/سخت و ثبت رویدادهای استفاده در Google Sheets آماده شده‌اند. **وضعیت عملیاتی:** تا زمانی که مالک نسخهٔ جدید `Code.gs` را در پروژهٔ Google Apps Script خودش جایگزین و ذخیره نکند، ربات زنده از آن استفاده نمی‌کند.

### فعال‌سازی مرحله‌ای در پروژهٔ قبلی

1. وارد پروژهٔ موجود `Payame Jadval Bot` در https://script.google.com/home شو.
2. **تمام** نسخهٔ تازهٔ [Code.gs](Code.gs) را کپی و به جای محتوای فایل Code.gs در گوگل قرار بده. Save بزن. Script Properties و توکن اختصاصی ربات با این کار پاک نمی‌شوند.
3. از فهرست توابع، `setupAnalytics` را انتخاب و یک بار Run کن. از تو برای ساخت Google Sheets خصوصی در Drive خودت مجوز خواسته می‌شود. دسترسی را بررسی و تأیید کن. این تابع **فقط یک شیت** می‌سازد و در دفعات بعد از ساخت دوباره خودداری می‌کند.
4. در **Execution log** لینک `https://docs.google.com/spreadsheets/d/.../edit` را می‌بینی. این **داشبورد خصوصی مدیر** است. دو تب «رویدادها» و «داشبورد» دارد.
5. لازم نیست `setupBot` را تکرار کنی چون trigger قبلی `pollUpdates` فعال است. پیام `/start` را در تلگرام ارسال کن و در صورت نیاز یک بار `testNow` را Run کن.
6. برای سودوکو، روی «🔢 سودوکو» سپس یکی از دکمه‌های آسان، متوسط یا سخت بزن. هر روز هر سه درجه از `data/daily-games.json` انتخاب می‌شوند و صرفاً پس از زمان `publishedAt` در دسترس‌اند؛ جدول هر درجه برای همهٔ کاربران در آن روز یکسان است.
7. برای بررسی آمار روی همان Sheet خصوصی، تب «داشبورد» را ببین؛ گزارش‌ها تنها از زمان فعال‌شدن `setupAnalytics` به بعد جمع می‌شوند. اگر لینک را گم کردی، در ویرایشگر تابع `analyticsLink` را Run کن؛ آدرس در Execution log چاپ می‌شود.

### دقیقاً چه آمارهایی ثبت می‌شوند؟

| رویداد | ثبت می‌شود؟ |
| --- | --- |
| شروع ربات و انتخاب هر بازی | بله، در صورت فعال‌بودن شیت آمار |
| تعداد شناسه‌های یکتای ناشناس | بله |
| تاریخ و زمان درخواست | بله |
| ارسال **موفق** جدول یا سودوکو | بله، به معنی پذیرش درخواست ارسال تلگرام |
| کلیک روی دکمهٔ اشتراک‌گذاری ربات | بله؛ **نه** تعداد واقعی فوروارد/کپی |
| بازکردن ویجت، حروف واردشده، زمان حل، پایان و امتیاز واقعی | **خیر**، تا فراهم‌شدن ارتباط فوری معتبر از ویجت |
| نام/نام کاربری کاربران | **فقط با رضایت صریح** `/showname`؛ پیش‌فرض ناشناس |

شناسهٔ کاربران در شیت، هش پایدارِ نمک‌دار است و **آی‌دی خام تلگرام ذخیره نمی‌شود**. کاربران با `/privacy` دربارهٔ داده‌ها مطلع می‌شوند، با `/hidename` نام را از سوابق حذف می‌کنند، و با `/forgetme` داده‌های موجود خود را پاک کرده و از ثبت‌های بعدی خارج می‌شوند. ماندگاری پیشنهادی ۹۰ روز است؛ یک Trigger روزانه برای پاک‌سازیِ بهترین‌تلاش ایجاد می‌شود.

**دقت:** `setupAnalytics` نیازمند اجازهٔ تازهٔ Google Sheets است. این کار خودکار انجام نمی‌شود و اجازهٔ دسترسی به Drive فقط در حساب گوگل مالک درخواست می‌شود. تا زمانی که کاربر آن را Run نکند، کد بازی همچنان اجرا می‌شود اما رویدادها ثبت نمی‌شوند.

### وضعیت سودوکو

سودوکوهای ۹×۹ روزانه قبلاً در مخزن موجود بوده‌اند. اکنون یک **ویجت بومی تلگرام** در `telegram/sudoku-widget-template.html` برای بازی داخل پیام طراحی شده است؛ سه درجهٔ آسان، متوسط و سخت و انتخاب ثابت روزانه از آرشیو معتبر. هر بازی لینک اختصاصی دعوت دارد:

`https://t.me/PayameJadvalBot?start=s_sudoku-YYYY-MM-DD-easy`

قابلیت ثبت نتیجهٔ واقعی و جدول رتبه‌بندی سودوکو هنوز وجود ندارد؛ امتیاز داخل ویجت فقط بازخورد **غیررسمی و محلی** است. هنگام بررسی خطا در GitHub نباید این امتیاز را آمار رسمی تلقی کرد.

## فعال‌کردن نسخهٔ تازه روی پروژهٔ موجود (مهم)

۱. از [Code.gs](Code.gs) تمام کد فعلی را کپی کن.

۲. پروژهٔ Google Apps Script قبلی با نام `Payame Jadval Bot` را در https://script.google.com/home باز کن؛ به **همان پروژهٔ موجود** برو، پروژهٔ دوم نساز.

۳. در ویرایشگر، محتوای `Code.gs` را با نسخهٔ تازه جایگزین و **Save** کن. مقدار ذخیره‌شده در **Project Settings → Script Properties → TELEGRAM_CROSSWORD_BOT_TOKEN** با تعویض کد پاک نمی‌شود؛ آن را داخل کد نگذار و در چت نفرست.

۴. معمولاً نیازی به اجرای دوبارهٔ `setupBot` نیست چون Trigger قبلیِ `pollUpdates` برقرار است. برای آزمایش، پس از Save در تلگرام `/start` بفرست، سپس تابع `testNow` را دستی Run کن یا اجرای خودکار دقیقه‌ای را بررسی کن. اگر Trigger از قبل حذف شده، **فقط آن‌وقت** `setupBot` را یک‌بار اجرا کن.

۵. منوی تازه باید ۷ گزینه داشته باشد: **⚡ جدول سریع، 🧩 جدول اصلی، 🔢 سودوکو، 🏆 چالش جمعه، 📚 آرشیو جدول‌ها، 🏅 امتیازهای من، 📤 اشتراک‌گذاری**.

۶. «جدول سریع» در **۱۱ و ۱۲ نوامبر ۲۰۲۶** دو نمونهٔ ۵×۵ از پیش منتشرشده را ارائه می‌کند. در تاریخ‌هایی که جدول تأییدشدهٔ تازه‌ای نداریم، ربات **صریحاً نبود جدول را اعلام می‌کند**. «جدول اصلی» تا انتشار جدول ۷×۷ معتبر روزانه، همان نمونهٔ آزمایشی ۷×۷ را با برچسب آزمایشی عرضه می‌کند.

۷. برای دیدن **دکمهٔ کپی لینک** و **امتیاز آزمایشی** باید جدول جدید را از ربات بگیری؛ HTML پیام‌های Widget قدیمی تغییر نمی‌کند. دکمهٔ «اشتراک‌گذاری» لینک مستقیم ورود به **همان جدول** در ربات، و یک لینک وب ویژهٔ همان جدول برای ارسال در پیام‌رسان‌های دیگر فراهم می‌کند.

## راه‌اندازی برای اولین بار

اگر اصلاً Google Apps Script فعال نکرده‌ای:
- با حساب گوگلت وارد https://script.google.com/home/projects/create شو و پروژهٔ `Payame Jadval Bot` بساز.
- کد [Code.gs](Code.gs) را جایگزین کن.
- در **Project Settings → Script Properties** مقدار محرمانهٔ `TELEGRAM_CROSSWORD_BOT_TOKEN` را از `@BotFather` ذخیره کن.
- یک بار `setupBot` را اجرا کن و مجوزهای موردنیاز Google Apps Script را بررسی و تأیید کن.
- `/start` را دوباره برای ربات بفرست و در صورت نیاز `testNow` را اجرا کن.

## محدودیت‌های فعلی

- این ربات هر **حدود یک دقیقه** پیام‌ها را بررسی می‌کند، نه فوراً. زمان دقیق اجرای trigger تضمین‌شده نیست.
- `widget_query` در تلگرام باید ظرف ۱۵ ثانیه پاسخ بگیرد و با **پولینگ یک‌دقیقه‌ای مناسب نیست**؛ بنابراین `allow_queries` غیرفعال است و **امتیاز رسمی سروری یا جدول رتبه‌بندی واقعی هنوز فعال نیست**.
- دو مینی ۵×۵ با تأیید اولیهٔ ویراستار از `data/mini-puzzles.json` برای ۱۱ و ۱۲ نوامبر در `telegram/catalog.json` زمان‌بندی شده‌اند. انتشار هر روزِ تازه به موجودی جدول‌های جدید و بازبینی بستگی دارد.
- چالش ۹×۹ جمعه تا افزودن سازگاری و کنترل کیفیت ۹×۹ و وجود جدول جدید فعال نمی‌شود.
- فوروارد مستقیم Widget در تلگرامِ عمومی پشتیبانی نمی‌شود؛ **اشتراک لینک خود جدول** جایگزین است.
- پل قدیمی GitHub با زمان‌بندی پنج‌دقیقه‌ای غیرفعال است. نسخهٔ زمان‌بندی‌شدهٔ این Apps Script و پل دستی GitHub را هم‌زمان اجرا نکن تا رویدادهای `getUpdates` از دست نروند.
- برای توقف `stopBot` را اجرا کن؛ ربات‌های دیگر دست‌نخورده می‌مانند.
