# پیام جدول | Payame Jadval

**سایت عمومی انتشار و حل جدول‌های طراحی‌شده و تأییدشده در `nimania/jadval`.**

- `jadval`: محیط مدیریت داخلی و طراحی؛ بانک سؤال‌وجواب و پیش‌نویس‌ها.
- `payamejadval`: نمایش فهرست جدول‌های منتشرشده و تجربهٔ حل جدول برای مخاطب.

ساختار دادهٔ عمومی در `data/published.json` قرار می‌گیرد؛ تا زمان اولین تأیید و انتشار، آرشیو خالی است. از انتشار خودکار جدول‌های خام/تست خودداری شود.

## راه‌اندازی GitHub Pages
در Settings → Pages، انتشار را از شاخهٔ main و پوشهٔ / (root) فعال کنید. بعد از انتشار، سایت در `https://nimania.github.io/payamejadval/` قرار می‌گیرد.

## قالب داده
فایل `data/published.json` آرایهٔ `puzzles` دارد. هر مدخل `id`، `title`، `publishedAt` و `puzzle` با ساختار v3 (`grid` و `clues`) را نگه می‌دارد. فقط خروجی‌های تأییدشده باید به آن اضافه شوند.

## گام بعد
اتصال ابزار تأیید جدول در مخزن `jadval` به انتشار نسخه‌های نهایی در این مخزن، ساخت صفحهٔ بازی و پاسخنامه با امکان پنهان‌سازی جواب‌ها.
