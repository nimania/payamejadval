# پیام جدول | Payame Jadval

**سایت عمومی انتشار و حل جدول‌های طراحی‌شده و تأییدشده در `nimania/jadval`.**

- `jadval`: محیط مدیریت داخلی و طراحی؛ بانک سؤال‌وجواب و پیش‌نویس‌ها.
- `payamejadval`: نمایش فهرست جدول‌های منتشرشده و تجربهٔ حل جدول برای مخاطب.

ساختار دادهٔ عمومی در `data/published.json` قرار می‌گیرد؛ تا زمان اولین تأیید و انتشار، آرشیو خالی است. از انتشار خودکار جدول‌های خام/تست خودداری شود.

## راه‌اندازی GitHub Pages
در Settings → Pages، انتشار را از شاخهٔ main و پوشهٔ / (root) فعال کنید. بعد از انتشار، سایت در `https://nimania.github.io/payamejadval/` قرار می‌گیرد.

## قالب داده
فایل `data/published.json` آرایهٔ `puzzles` دارد. هر مدخل `id`، `title`، `publishedAt` و `puzzle` با ساختار v3 (`grid` و `clues`) را نگه می‌دارد. فقط خروجی‌های تأییدشده باید به آن اضافه شوند.

## گام بعد
اتصال ابزار تأیید جدول در مخزن `jadval` به انتشار نسخه‌های نهایی در این مخزن، ساخت صفحهٔ بازی و پاسخنامه با امکان پنهان‌سازی جواب‌ها.


## بازی آنلاین و انتشار مستقیم (نوامبر ۲۰۲۶)

- بازی راست‌به‌چپ با گروه‌بندی سرنخ‌های هر سطر/ستون، ذخیرهٔ محلی پیشرفت، بررسی پاسخ‌ها، پاسخنامه و لینک مستقیم جدول فعال شده است.
- داده‌های عمومی هم از آرشیو موجود `data/published.json` و هم از مجموعهٔ Firestore `publishedPuzzles` خوانده می‌شوند.
- مدیر در سایت `nimania/jadval` پس از کامل‌بودن جدول، تأیید سرنخ‌ها و تأیید صریح ویراستاری، می‌تواند یک جدول تازه بسازد. انتشار خودکار وجود ندارد.
- قواعد Firestore برای `publishedPuzzles`: خواندن عمومی، ایجاد فقط توسط مدیر Google تأییدشده، ویرایش و حذف از مرورگر ممنوع.
- ساختار صفحهٔ عمومی Firestore شامل `id`، `title`، `size`، `publishedAt`، `approvedBy`، `editorApproved` و `puzzleJson` است. `puzzleJson` حاوی JSON نسخهٔ v3 است، زیرا Firestore آرایهٔ تودرتو را نمی‌پذیرد.
- **ضروری:** قوانینِ ویرایش‌شدهٔ `nimania/jadval/firebase/firestore.rules` تا زمان انتشار دستی روی Firebase **صرفاً در GitHub هستند**. آزمون شبیه‌ساز، استقرار روی پروژهٔ واقعی نیست.
- کل بانک سؤال‌وجواب خصوصی می‌ماند و هیچ دادهٔ آزمونی یا نمونهٔ بازبینی‌نشده‌ای به آرشیو اضافه نشده است.

راهنمای فعال‌سازی در `nimania/jadval/docs/publish-payamejadval.md` قرار دارد.
